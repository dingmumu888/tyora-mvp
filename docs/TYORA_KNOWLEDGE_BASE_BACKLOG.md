# TYORA 知识库收尾任务

## 触发时间

完成前台到后台的全流程测试，并由用户确认网站测试通过、可以正式上线后执行。

## 目标

把网站开发和测试期间确认的产品结论整理成 TYORA 可持续维护的知识库，供产品、运营、客服、制造团队和后续开发共同使用。

## 计划收录范围

1. TYORA 产品定位与目标客户
2. 社区、制造、找货、私密定制等核心功能逻辑
3. 注册、邮箱验证、个人资料和会员使用流程
4. 发帖、图片、问题选择、审核、评论和 TYORA 评估流程
5. Source 每周爆款、询盘统计、自动下架与清理规则
6. 品牌语言、页面气氛和多语言原则
7. 后台内容、客户、帖子、询盘、项目和权限操作
8. Supabase、正式数据库迁移、数据重置和安全注意事项
9. 上线测试记录、已验证功能、已知限制和待优化项目
10. 日常运营标准、客服回复原则和常见问题

## 整理规则

- 仅把已经确认的结论写成正式规则。
- 尚未决定的想法单独放入“待讨论”区域。
- 每项内容尽量记录日期、状态、关联页面和操作方法。
- 面向非技术人员编写，避免只有开发人员才能理解。
- 产品规则、操作手册和技术维护说明分开组织。

## 当前已确认的首项原则

- 品牌定位：热情的产品创作者社区，同时提供可信的制造支持。
- 社区和创作流程保持有感染力、有行动感；制造、价格、隐私和法律内容保持专业、清楚、可信。
- 六种语言的含义和品牌语气需要保持一致。
