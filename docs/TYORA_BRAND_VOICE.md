# TYORA 品牌语言原则

## 核心定位

TYORA 是一个充满行动力的产品创作者社区，同时提供可靠、专业的制造支持。

品牌体验应让客户产生三种感受：

1. 我的创意值得分享。
2. 我现在就想迈出下一步。
3. TYORA 有能力帮助我把创意变成真实产品。

## 两种使用语气

### 热情、有感染力

适用于社区、发帖、个人主页、注册引导、创作进度和成功反馈。

- 鼓励表达创意，而不是平淡地要求填写资料。
- 使用真实、具体、有行动感的语言。
- 先唤起期待，再告诉客户下一步做什么。

示例：

- “灵感别藏着！告诉大家它解决什么问题，以及你为什么想把它做出来。”
- “继续，让创意更接近现实。”
- “告诉 TYORA：你最想先弄清什么？”

### 专业、清楚、可信

适用于制造评估、供应链、价格、付款、隐私、授权和法律内容。

- 准确说明范围、条件、风险和下一步。
- 不使用夸张承诺，不制造虚假紧迫感。
- 让客户知道 TYORA 认真对待他的创意和商业决定。

## 禁止倾向

- 不要让每句话都像广告口号。
- 避免“快快快”“保证成功”“一定会成为下一个乔布斯”等过度表达。
- 不预先宣称客户的创意“伟大”或“改变世界”。
- 避免空泛、模板化、AI 味明显的鼓励语。

## 推荐结构

公开页面文案优先采用：

1. 情绪邀请：让客户想表达、参与或继续。
2. 具体行动：明确告诉客户现在做什么。
3. 专业保障：说明 TYORA 会怎样认真处理。

## 持续检查

以后新增或修改前台页面时，需要主动检查并提醒：

- 文案是否过于平淡，缺少分享欲和行动感。
- 文案是否过度夸张，影响专业信任。
- 排版是否突出情绪邀请和主要行动。
- 六种语言是否保持相同品牌语气与含义。
